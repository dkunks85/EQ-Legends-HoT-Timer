EQ Legends Spell Timer v7.1

START THE APP WITHOUT A COMMAND WINDOW:
  Double-click Run-EQSpellTimer-v7.1.vbs

The .bat launcher is included as a fallback, but the .vbs launcher is the recommended one.

v7.1 fixes configuration migration errors from older spells.json files. Existing spell values are preserved, and only genuinely missing properties are added.

Alacrity ranks are matched automatically from one Alacrity row. The landing message "You feel much faster." is treated as a self-buff and uses the character name from the EQ log filename.
